# BLE协议 v1

服务43710000-9d6f-4b8a-9d30-524144494f01；命令43710001…；状态43710002…。ATT write-with-response及notify/read，要求加密链路，包固定10字节，不传电话号码。

| 偏移 | 格式 | 含义 |
| --- | --- | --- |
| 0 | u8 | 协议版本1 |
| 1 | u8 | 操作码/事件码 |
| 2 | u32 LE | 本连接递增序号，从1开始 |
| 6 | u32 LE | 参数/状态位 |

命令：1=同步本地分钟[0,1439]；2=启动提醒；3=停止；4=单次试听；5=音色0/1；6=音量0/1/2。固件拒绝重复/倒序、未知操作、错误长度或非法参数。物理键不占用手机序号。重连清序号和时钟、停止提醒；App先订阅再同步，不重发旧提醒。

状态事件0x80=普通状态，0x81=前面单键手动停止本轮提醒（不代表已查看手机）；序号为最近已处理命令。arg：bit0正在提醒，bit1时间有效，bit2夜间静音，bit3BLE已连，bit4音色，bit5–6音量，bit8电压估算低于3.45V。初始低电标志未测量，不代表百分比。无有效时钟时bit2不作为判断依据。状态每10秒/命令处理/按键更改更新。App GATT串行队列；20秒操作超时重连，10秒重试间隔。GATT写成功仅表示传输完成，设备状态通知才反映最终状态。
