# 薄型漏接提醒器按键与音频载板

52×26mm、1mm FR4双层、1oz铜；保留XIAO nRF52840基础版和FLY.502728.390 390mAh保护电池。载板承载四键、PAM8302AASCR、滤波外围及后置充电口。XIAO与电池在载板后部并排，整机总厚度19.05mm。

## 发布与检查

当前发布bbae20a434339443ea3c5a5be6bef92bbbb1d6c7cf2214563fcd01bb77dd2b27，制作/装配/机械三部分均就绪。0电气/间距错误、0未连接，原始KiCad另有4条丝印重叠提示。顶/底布线、供应商引脚及机械孔已检查；过孔0.6/0.3mm，USB有4个0.8mm镀孔长槽及2个0.6mm定位孔。无手画近似封装。

F.Cu局部地岛通过(13.4,0.8)的0.6/0.3mm过孔接到B.Cu，已检查两面完整过孔圆落在同网填铜内，且避开焊盘。VBAT 0.35mm、最小0.3mm，按0.25W提示音、最低3V/80%效率约104mA平均及250mA裕量设计。USB5V按150mA预算、实际0.25mm线宽匹配0.27mm插座焊盘。

## 连接与充电

取消J_CTRL高排针，10根30AWG柔软短线由下面焊点接XIAO，线长约50mm，余线平铺留拆盖维修余量，载板背面焊点及贴板走线高度≤0.8mm。不要按旧版排针脚序连接。

| --- | --- |
| TP1 VBAT | 电池P+及XIAO BAT+ |
| TP2 GND | 电池P-及XIAO GND |
| TP3 SPKP / TP4 SPKN | 扬声器两端，均不能接地 |
| TP5 PWM | D0/P0.02 |
| TP6 AMP_EN | D1/P0.03 |
| TP7 SOUND | D2/P0.28 |
| TP9 VOL_UP | D4/P0.04 |
| TP10 VOL_DOWN | D5/P0.05 |
| TP11 POWER | D6/P1.11 |
| TP12 V3V3 | 3V3_OUT |
| TP13 USB5V | XIAO 5V/VBUS |

新后口GT-USB-7096C C19188081，垂直高8.5±0.2mm，B面安装，坐标(17.4,9)。厂家图的B12/B1/A12/A1接GND，B9/B4/A9/A4接USB5V，B5为CC2、A5为CC1；每路各经5.1k到GND，屏蔽焊脚也接GND。数据和SBU脚有意悬空；后口只充电，不支持USB数据及PD。采用精确供应商封装，底面镜像由编译器处理。

依据官方wiki及v1.2原理图，XIAO 5V就是VBUS，接至板载BQ25101输入；充电仍由XIAO管理，P0.13设高约50mA，低于电池标准78mA。原XIAO USB留在壳内供拆盖编程。编程前拔掉后口电源，不同时连接两路USB，因为两口VBUS相连。没有电池实时测温，TS为固定电阻；按厂家0–45℃充电要求使用，充电终止及负载影响须实测。

## 按键与音频

前多功能换音键与后电源：TS-1187A-B-A-B C318884共2颗，1/2脚为信号同侧，3/4脚为GND同侧。顶部音量：TS24CA C393942，两个支撑焊脚接GND。后电源移至(7,9)，与Type-C中心同高；前键和顶部两键X/Z位置保留。

PAM8302AASCR是MSOP8专用脚序：1 SD、2 IN-、3 IN+、4 NC、5 OUT+、6 VDD、7 GND、8 OUT-。VBAT供电；SD外部10k下拉。两级10k/10nF低通、10k/1k衰减、两路100nF匹配耦合、1uF及2×10uF旁路。输出桥接扬声器，额定0.8W，初始提示功率上限0.25W需固件约束。未加输出EMC磁珠，不宣称EMC已验证。

电源键长按2秒是固件关机，停止BLE并拉低SD，System OFF由按键唤醒；不是物理断电。固件已提供可编译验证版，待真机测试。

## Making and assembly

USB及两只新增CC电阻采用手工焊接，不包含在JLC SMT文件中；其余按贴片清单装配。USB为0.785mm间距，使用放大镜核对两排焊脚及定位孔，先做无源连通/短路检查再接电池。四键上拉/复位状态与音频渐强须固件实现。

载板沿外壳定位轨装入，前挡两边点柔性电子胶、下缘后挡加0.3mm垫。线束绕电池上下边缘走，不夹在电芯上。主控元件面朝前、原USB朝壳内右侧，后面薄胶固定；先量测实际主控高度。XIAO天线邻近电池和载板，BLE连接范围与耗电需首件测量，不把CAD装入当作射频验证。外壳装配说明给出打印、螺钉和按帽顺序。

App、固件、声学响度、72小时续航、充电温升、天线和机械承载未实测，设计包通过不等于功能样机通过。

## 前面单键与布线
正面SW_SOUND移到(0,-4)，原上方(0,7)不再装开关。删除SW_ACK、TP8及ACK网络，XIAO D3不接线；其余焊点编号保持，连接线10根。待机短按换音并试听、提醒中短按只停止并清零、长按3秒配对；App中的“我已查看手机”仍可停止。为重新布线，将C_INP移到(23.8,1.8)、C_INN移到(24.4,-3)、C_HF移到(13,-1)、R_SD移到(18.5,-7)，器件型号/数值与其他外部接口不变；全部网络重新布线后0电气/间距错误、0未连接，4条丝印重叠提示。

背面布局采用电源与Type-C同高横排；只改变SW_PWR位置，D6、上拉电阻、10线接法和0.2.0固件保持兼容，无须因位置变化重新烧录。
