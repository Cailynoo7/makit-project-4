# 先读这里：首次安装与测试

这是0.1.0软件验证版，需要一部Android手机及已按接线图连接的XIAO/载板。APK可直接安装，不需要你开发或上架App。首次安装、授权及固件烧录由子女或装配人员完成。

## 1. 给挂件烧录固件

1. 若已装壳，打开后盖使用XIAO原本的USB口；后置充电口没有数据线，不能用于烧录。编程前拔掉后置口的充电线，两口不可同时供电。
2. 用可传数据的USB线连接XIAO与电脑，快速双击板上的RESET小按钮，进入引导模式。
3. 如果电脑出现BOOT磁盘，查看其中INFO_UF2.TXT，确认是XIAO nRF52840基础版及S140 7.3.0兼容环境，然后把本包的 `radio-reminder-xiao-nrf52840.uf2` 拖入该磁盘；复制完成后挂件会重启。
4. 本固件是应用程序，不替换引导程序或SoftDevice。若没有BOOT磁盘、版本不匹配或文件复制后没有启动，请把显示信息交给设计助手继续处理。本包另含串口DFU备选包，不要自行擦除整片Flash。
5. 新手机配对窗口为开机后60秒；超时可长按前面换音键3秒重新开启60秒。首次测试从最低音量开始。

## 2. 手机安装

1. 把本包的 `radio-reminder-validation.apk` 传到手机，打开安装。Android可能要求允许当前文件管理器安装未知应用，按系统提示对该安装来源授权。
2. 应用名为“收音机提醒·验证版”。打开后按页面顺序授予电话、附近设备及通知权限；Android 8–11蓝牙扫描还需要定位授权与系统定位开关。
3. 点“允许读取系统未接通知”，在系统通知读取列表中启用本应用。Android 13及以上若提示“受限设置”，在本应用的系统应用信息页检查是否提供“允许受限设置”，确认是本项目安装包后再授权；不同品牌入口可能不同。受系统或组织策略禁止时，请反馈手机型号与提示内容。
4. 可以尝试“可选：授权通话记录，核验未接/拒接”。这是Android受限制的权限，系统可能不给授权，反复点授权不会解决安装渠道的限制。
5. 有通话记录权限时自动使用严格核验模式；没有时，默认不自动计数。若要继续真实来电试验，可明确打开“启用通知兼容模式（可能误计拒接）”。该路径不保证区分主动拒接。
6. 点“查找附近挂件”，选择自己手边的收音机，确认系统配对提示，等待“挂件已连接”和时间有效。一次只开启一个待配对挂件。
7. 按手机品牌的应用设置允许后台运行，保留运行通知。手机重启后需点提示或打开App恢复连接；验证版尚未做到所有品牌无操作恢复。

## 3. 先做五分钟链路试验

白天06:00–22:00进行。

| 操作 | 预期 |
| --- | --- |
| 点“试听一次” | 挂件播放一次短提示 |
| 按前面换音键 | 两种提示音切换并试听 |
| 按顶部音量± | 在低/中/高三档饱和调整 |
| 将手机设为静音，点“模拟一通漏接”两次 | 不启动重复提醒 |
| 第三次模拟 | 启动每10秒一轮提示，至多2分钟 |
| 按挂件确认键 | 立即停止、计数清零 |
| 再模拟三次，点“我已查看手机” | 停止提醒 |
| 模拟提醒后关闭手机蓝牙 | 挂件停止；重连不补响 |
| 长按电源2秒后松开，再持续按2秒开机 | 关机/唤醒；重连后重新同步时间 |

模拟仍受手机静音/勿扰与夜间规则约束。模拟期间真实漏接不混入测试计数；完成后点“清空计数与停止提醒”恢复真实监听。模拟通过不代表系统来电识别已经通过。

## 4. 再测真实电话

退出模拟并清零，手机保持静音，服务与挂件保持连接。用另一部手机在10分钟内拨3通，每通等它自然结束，勿手动拒接。检查前2通不提醒、第3通结束后提醒。然后分别测试实体确认、接听/回拨、点击系统未接通知能否停止。

主动拒接必须单独试：严格模式应显示拒接且不增加计数；兼容模式若系统发出未接通知，可能误计，需要记录品牌、系统版本和运行记录。只亮屏/解锁不会被当成已查看，未经过通知的查看请使用App或实体确认键。

夜间22:00–06:00应不发声；无时钟同步时应无声；06:00不集中补响。不要把“模拟通过”记录为“真实电话通过”。

## 5. 把结果反馈给设计助手

请提供手机品牌型号、Android/系统版本、采用严格还是兼容模式、哪个步骤的预期没有出现，以及页面运行记录的文字。不要发电话号码或完整通话记录。必要时再针对该机型调整通知识别和后台策略。

已完成：APK编译/签名校验、XIAO目标编译、UF2内容检查、逻辑测试。
尚未完成：本手机安装启动、BLE加密订阅、真实来电联调、音频电气/响度、按键唤醒与长时间后台测试。不能据此承诺72小时续航或跨品牌可靠性。
